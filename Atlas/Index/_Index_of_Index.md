# Atlas/Index 索引

## 📊 统计概览

```dataviewjs
const indexPages = dv.pages('"Atlas/Index"');
dv.paragraph(`总文件数: ${indexPages.length}`);

// 按类型分类
const dataviewFiles = indexPages.where(p => p.file.name.includes("Dataview"));
const taskFiles = indexPages.where(p => p.file.name.includes("任务") || p.file.name.includes("Task"));
dv.table(["类型", "文件数"], [
  ["Dataview 查询", dataviewFiles.length],
  ["任务管理", taskFiles.length],
  ["其他", indexPages.length - dataviewFiles.length - taskFiles.length]
]);
```
